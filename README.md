An optimized fork of marked 18.1.3 for the [markdown-render-speed-02 competition](https://make.fun/bounty/markdown-render-speed-02). It preserves marked's default HTML output with dependency-free JavaScript and a Node 22 driver.

Run `node main.ts` to read `/input/cases.json` and write `/output/html.json`. The parser exports `parse(markdown)` from `parse.js`. Upstream source: [marked v18.1.3](https://github.com/markedjs/marked/tree/v18.1.3); see LICENSE and NOTICE.
